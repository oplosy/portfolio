# Design Decisions Notes

A log of design decisions behind the portfolio, kept brief so it stays updated.

## Decisions so far

- Single-page portfolio with a content layer in `data/` — keeps content editable without touching components.
- `DESIGN.md` is the visual contract; component changes must stay within it.
- `scrollcraft/` holds the scroll/animation experiments that the main sections reuse.

## Process

- A decision that changes layout, theming, or content structure goes here first.
- Reversing a decision gets a new entry; don't rewrite history.

Short entries only — this is a ledger, not an essay.
